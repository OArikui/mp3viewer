# MP3 Viewer v0.3.0

Rust製のMP3メタデータ参照・編集アプリ(egui + egui_extras + lofty + image)。

## ビルド・実行

```
cargo run --release
mp3viewer --version
```

## 機能

| # | 機能 | 場所 |
|---|------|------|
| ① | メタデータ参照・編集(タイトル/アーティスト/アルバム/アルバムアーティスト/ジャンル/年/トラック) | 「メタデータ」タブ |
| ② | 指定ディレクトリ内のmp3を再帰取得 | 「ディレクトリを開く」 |
| ③ | デフォルトディレクトリ設定(起動時に自動で開く) | 「デフォルトに設定」 |
| ④ | ディレクトリ構成からアルバム/アーティストを設定・書き込み | メタデータタブ下部 |
| ⑤ | ジャンル候補(説明付き)JSONの作成・編集 | 「ジャンル候補」タブ |
| ⑥ | ジャンル候補のインポート(マージ/置換)・エクスポート | 「ジャンル候補」タブ |
| ⑦ | ジャンル別/アルバム別/アーティスト別/追加日別/リリース年別/曲名頭文字別のグループ表示・並び替え | 左ファイル一覧「表示順 / グループ」 |
| ⑧ | 曲名・アーティスト・アルバム・ジャンル・ファイル名を対象とした検索 | 左ファイル一覧「検索」 |
| ⑨ | ファイル一覧のテーブル表示(サムネイル/曲名/アーティスト/アルバム/ジャンル/年を列表示) | 左ファイル一覧 |
| ⑩ | アーティスト・ファイル(メディア)・アルバムの埋め込み画像をサムネイル表示 | 左ファイル一覧の各行 |

## ファイル一覧(テーブル)の見方

左側はテーブル形式で、列は左から「アーティストのサムネ / ファイル(メディア)のサムネ / アルバムのサムネ / 曲名 / アーティスト / アルバム / ジャンル / 年」です。
曲名セルをクリックすると選択できます。「表示順 / グループ」で並び替え軸を選ぶと、見出し行付きでグループ分けされます。

- **追加日別**: ファイルの作成日時(取得できない環境では更新日時)を `YYYY-MM-DD` で日単位グループ化
- **リリース年別**: mp3タグの年情報(YYYY)でグループ化。mp3タグの仕様上、月日までは扱えません
- 未設定の項目は `(ジャンル未設定)` のようにグループ化されます

検索は曲名・アーティスト・アルバム・ジャンル・ファイル名のいずれかに部分一致すれば該当します。

### サムネイルについて

サムネイルはmp3ファイルに埋め込まれた画像(ID3 APICフレーム)から、画像の種別(PictureType)ごとに取得しています。

| 列 | 対応する PictureType |
|---|---|
| アーティスト | `Artist` / `LeadArtist` |
| ファイル(メディア) | `Media` |
| アルバム | `CoverFront`(無ければ埋め込み画像のうち最初のものを代用) |

一般的なmp3ファイルはアルバム表紙(`CoverFront`)のみを埋め込んでいることが多く、アーティストやメディアの画像が埋め込まれていない場合、該当するサムネイルは「–」と空欄表示になります。これはアプリの不具合ではなく、ファイルにその種別の画像が埋め込まれていないことを示します。

サムネイルは各ファイルが初めて一覧に表示されたタイミングでデコードしてキャッシュします。ディレクトリを開いた直後や、検索・グループ表示で新しい行が表示された際に、埋め込み画像が多いと一瞬もたつく場合があります。

## ディレクトリ構成の規則

`ルート/アーティスト/アルバム/曲.mp3`(ルートは「ディレクトリを開く」で選んだフォルダ)

- 階層が2つ以上: 末尾から2番目=アーティスト、末尾=アルバム
- 階層が1つ: アルバムのみ
- ルート直下: 設定なし(スキップ)

## 保存ファイル

設定フォルダ(OS標準の config ディレクトリ)/`mp3viewer/` 配下

- `config.json` — デフォルトディレクトリ
- `genres.json` — ジャンル候補 `{"version":1,"genres":[{"name":"Rock","description":"..."}]}`
  (インポートは `[{"name":..,"description":..}]` 形式の配列も可)

## バージョン管理

- `CHANGELOG.md` — [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) 形式の変更履歴
- `docs/COMMIT_CONVENTION.md` — コミットメッセージ規約([Conventional Commits](https://www.conventionalcommits.org/ja/v1.0.0/) ベース)
- `.gitmessage.txt` — コミットテンプレート(`git config commit.template .gitmessage.txt` で設定)
- `docs/COMMIT_MESSAGE_v0.2.0.txt` / `docs/COMMIT_MESSAGE_v0.3.0.txt` — 各バージョンのコミットメッセージ例(`git commit -F docs/COMMIT_MESSAGE_v0.3.0.txt` でそのまま利用可)
- `.gitignore` — `/target` 等を除外。バイナリアプリのため `Cargo.lock` はコミット対象

## 備考

- 日本語表示のため、OS標準の日本語フォント(游ゴシック/メイリオ/ヒラギノ/Noto CJK)を自動検出して使用します。
- ディレクトリを開いた時点で全mp3のタグを読み込みキャッシュします(テーブル表示・検索・グループ表示のため)。数千曲規模の非常に大きなライブラリでは初回読み込みに時間がかかる場合があります。
- 一覧表示は仮想化しておらず、検索・グループ条件に該当する行を毎フレーム全件構築します。非常に大きなライブラリでは表示の描画負荷にご注意ください。
