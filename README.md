# MP3 Viewer v0.1.0

Rust製のMP3メタデータ参照・編集アプリ(egui + lofty)。

## ビルド・実行

```
cargo run --release
mp3viewer --version
```

## 機能

| #   | 機能                                                  | 場所          |
| --- | --------------------------------------------------- | ----------- |
| ①   | メタデータ参照・編集(タイトル/アーティスト/アルバム/アルバムアーティスト/ジャンル/年/トラック) | 「メタデータ」タブ   |
| ②   | 指定ディレクトリ内のmp3を再帰取得                                  | 「ディレクトリを開く」 |
| ③   | デフォルトディレクトリ設定(起動時に自動で開く)                            | 「デフォルトに設定」  |
| ④   | ディレクトリ構成からアルバム/アーティストを設定・書き込み                       | メタデータタブ下部   |
| ⑤   | ジャンル候補(説明付き)JSONの作成・編集  | 「ジャンル候補」タブ  |
| ⑥   | ジャンル候補のインポート(マージ/置換)・エクスポート                         | 「ジャンル候補」タブ  |

## ディレクトリ構成の規則

`ルート/アーティスト/アルバム/曲.mp3`(ルートは「ディレクトリを開く」で選んだフォルダ)

- 階層が2つ以上: 末尾から2番目=アーティスト、末尾=アルバム
- 階層が1つ: アルバムのみ
- ルート直下: 設定なし(スキップ)

## 保存ファイル

設定フォルダ(OS標準の config ディレクトリ)/`mp3viewer/` 配下

- `config.json` — デフォルトディレクトリ
- `genres.json` — ジャンル候補 `{"version":1,"genres":[{"name":"Rock","description":"..."}]}`
  (インポートは `[{"name":..,"description":..}]` 形式の配列も可)

## 備考

- 日本語表示のため、OS標準の日本語フォント(游ゴシック/メイリオ/ヒラギノ/Noto CJK)を自動検出して使用します。
